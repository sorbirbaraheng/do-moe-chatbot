## 1. ภาพรวมระบบ

### 🎯 DO-MOE AI คืออะไร?
**DO-MOE AI** คือระบบ Chatbot อัจฉริยะที่ออกแบบมาเพื่อตอบคำถามเกี่ยวกับ **ข้อมูลการศึกษา** ของกระทรวงศึกษาธิการ โดยใช้เทคโนโลยี AI ขั้นสูง (Large Language Model) ผสมผสานกับฐานข้อมูลจริงของโรงเรียนทั่วประเทศ

### 🌟 จุดเด่นหลัก
| จุดเด่น | รายละเอียด |
|---------|------------|
| **ข้อมูลจริง Real-time** | ดึงข้อมูลจากฐานข้อมูลโรงเรียนจริง ไม่ใช่ AI คิดเอง |
| **ภาษาไทยธรรมชาติ** | ถาม-ตอบด้วยภาษาไทยธรรมชาติ ไม่ต้องจำคำสั่ง |
| **ครอบคลุมทั่วประเทศ** | ข้อมูลโรงเรียนกว่า 30,000+ แห่งทั่วประเทศ |
| **ใช้งานง่าย** | ไม่ต้องติดตั้ง ใช้ผ่าน Browser ได้เลย |

## 2. ฟีเจอร์หลัก

### 🔍 2.1 ค้นหาข้อมูลโรงเรียน
- **นับจำนวนโรงเรียน** ตามจังหวัด/เขต/สังกัด
- **ค้นหารายชื่อ** โรงเรียนในพื้นที่
- **ดูรายละเอียด** โรงเรียนเฉพาะแห่ง

**ตัวอย่างคำถาม:**
```
"โรงเรียนในจังหวัดปัตตานีมีกี่โรง"
"โรงเรียน สพฐ ในภาคใต้มีทั้งหมดกี่แห่ง"
"ข้อมูลโรงเรียนเบญจมราชูทิศ"
```

### 📊 2.2 จัดอันดับและเปรียบเทียบ
- **จังหวัดไหนมีโรงเรียนมากที่สุด/น้อยที่สุด**
- **เปรียบเทียบระหว่างจังหวัด**
- **แสดงกราฟสถิติ** (Bar Chart)

**ตัวอย่างคำถาม:**
```
"จังหวัดไหนในภาคใต้มีโรงเรียนมากที่สุด"
"เปรียบเทียบปัตตานีกับยะลา"
```

### 🗺️ 2.3 แผนที่โรงเรียน
- แสดงตำแหน่งโรงเรียนบนแผนที่
- กดดูรายละเอียดได้ทันที

### 💬 2.4 โหมดการใช้งาน 3 โหมด
| โหมด | ไอคอน | ใช้สำหรับ |
|------|-------|----------|
| **ข้อมูลทั่วไป** | 💬 | ถามเรื่องทั่วไป ระเบียบ คู่มือ |
| **ข้อมูลโรงเรียน** | 🏫 | ค้นหา นับ เปรียบเทียบโรงเรียน |
| **สถิตินักเรียน** | 📊 | ข้อมูลจำนวนนักเรียน สถิติ |

### 🔒 2.5 ระบบ Admin Panel
- ตั้งค่า API Keys (Gemini, Groq)
- ปรับแต่ง System Prompt
- ดู Session Monitor
- ทดสอบการเชื่อมต่อ

## 3. วิธีการใช้งาน

### 👤 สำหรับผู้ใช้ทั่วไป

**ขั้นตอนที่ 1:** เข้าเว็บไซต์ระบบ
```
http://[IP_ADDRESS]:3000
```

**ขั้นตอนที่ 2:** Login ด้วย Google Account

**ขั้นตอนที่ 3:** เลือกโหมดที่ต้องการ (ซ้ายมือ)
- 💬 ข้อมูลทั่วไป
- 🏫 ข้อมูลโรงเรียน
- 📊 สถิตินักเรียน

**ขั้นตอนที่ 4:** พิมพ์คำถามในช่อง Chat

**ขั้นตอนที่ 5:** รอระบบตอบ (ใช้เวลา 2-5 วินาที)

### 🛠️ สำหรับ Admin

**เข้า Admin Panel:**
1. กด Avatar มุมขวาบน
2. เลือก "การตั้งค่าแอดมิน"
3. หรือเข้าผ่าน URL: `http://[IP]:3000/admin`

**สิ่งที่ Admin ทำได้:**
- ✅ เพิ่ม/ลบ API Keys
- ✅ ปรับ System Prompt ตามที่ต้องการ
- ✅ ทดสอบการเชื่อมต่อ Flask/Qdrant
- ✅ ดู Session ที่กำลังใช้งาน

## 4. ประโยชน์ตามกลุ่มผู้ใช้

### 👨‍🎓 สำหรับผู้ใช้งานทั่วไป (บุคลากร/ประชาชน)
| ประโยชน์ | รายละเอียด |
|----------|------------|
| **ประหยัดเวลา** | ไม่ต้องค้นหาจากหลายแหล่ง ถามครั้งเดียวได้คำตอบ |
| **ใช้งานง่าย** | พิมพ์ภาษาไทยธรรมชาติ ไม่ต้องจำคำสั่ง |
| **ตอบได้ 24/7** | ใช้งานได้ตลอดเวลา ไม่ต้องรอเจ้าหน้าที่ |
| **ข้อมูลถูกต้อง** | ดึงจากฐานข้อมูลจริง ไม่ใช่ AI เดา |

### 🔧 สำหรับ Admin/IT
| ประโยชน์ | รายละเอียด |
|----------|------------|

| **Monitor ได้** | ดู Session และ Log การใช้งาน |
| **ไม่ต้องพึ่งพา Vendor** | ระบบเป็นของหน่วยงานเอง |
| **ขยายได้ง่าย** | เพิ่มข้อมูลใหม่ได้โดยไม่ต้องแก้ Code |

| ประโยชน์ | รายละเอียด |
|----------|------------|
| **ลดภาระงานบุคลากร** | AI ตอบคำถามซ้ำๆ แทนเจ้าหน้าที่ |
| **เพิ่มประสิทธิภาพ** | บุคลากรมีเวลาทำงานที่สำคัญกว่า |
| **ภาพลักษณ์ทันสมัย** | แสดงถึงการนำเทคโนโลยี AI มาใช้ |
| **ข้อมูลเชิงลึก** | ดูสถิติการใช้งาน/คำถามยอดนิยม |
| **ประหยัดงบ** | ใช้ LLM ฟรี (Groq) + Open Source |

## 5. เทคโนโลยีที่ใช้

### 🧠 AI/LLM
| เทคโนโลยี | บทบาท |
|-----------|-------|
| **Groq (llama-3.3-70b)** | LLM หลัก - เร็ว ฟรี |
| **Google Gemini** | LLM สำรอง - เสถียร |
| **Text Embedding** | แปลงข้อความเป็น Vector |

### 🗄️ ฐานข้อมูล
| เทคโนโลยี | บทบาท |

| **Redis** | Cache คำตอบซ้ำ (เร็วขึ้น) |
| **Firebase** | Authentication + Config Sync |

### 🌐 Frontend/Backend
| เทคโนโลยี | บทบาท |
|-----------|-------|
| **React + Vite** | หน้าเว็บ (Frontend) |
| **Flask (Python)** | API Backend |

## 6. สิ่งสำคัญที่ต้องรู้

### ⚠️ ข้อจำกัดปัจจุบัน
| ข้อจำกัด | คำอธิบาย |
|----------|----------|
| **ต้องมี Internet** | ระบบต้องเชื่อมต่อ Qdrant Server ภายนอก |
| **ข้อมูลมีวันที่** | ข้อมูลโรงเรียนอาจไม่ Real-time 100% (ต้องอัปเดต) |
| **API Quota** | LLM ฟรีมี Limit ต่อวัน (~14,400 req/day) |

### 🔐 ความปลอดภัย
- ✅ Login ผ่าน Google (ปลอดภัย)
- ✅ API Keys เก็บใน Firestore (Encrypted)
- ✅ ไม่เก็บข้อมูลส่วนบุคคลผู้ใช้
- ✅ Session หมดอายุอัตโนมัติ

### 💰 ค่าใช้จ่าย
| รายการ | ค่าใช้จ่าย |
|--------|-----------|
| **Groq API** | ฟรี (Rate Limit) |
| **Gemini API** | ฟรี Tier มี Quota |
| **Qdrant Cloud** | ฟรี 1GB |
| **Firebase** | ฟรี Tier เพียงพอ |
| **Hosting** | ขึ้นอยู่กับหน่วยงาน |
