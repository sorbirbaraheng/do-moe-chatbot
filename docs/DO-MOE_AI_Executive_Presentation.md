## ภาพรวมโครงการ

### 🎯 วิสัยทัศน์
**"ทำให้ข้อมูลการศึกษาของประเทศไทยเข้าถึงได้ง่าย ผ่านการสนทนาภาษาธรรมชาติ"**

### 📖 คำอธิบายโครงการ
**DO-MOE AI** เป็นระบบ AI Chatbot ที่พัฒนาขึ้นเพื่อให้บริการข้อมูลสถานศึกษาทั่วประเทศไทย ผู้ใช้สามารถถามคำถามเป็นภาษาไทยตามธรรมชาติ และได้รับคำตอบที่ถูกต้อง ครบถ้วน พร้อมข้อมูลเชิงลึกจากฐานข้อมูล **56,881 สถานศึกษา** ครอบคลุม **77 จังหวัด** ทุกสังกัดการศึกษา

### 🏆 จุดเด่นที่แตกต่าง
| จุดเด่น | รายละเอียด |
|---------|-------------|
| **ภาษาธรรมชาติ 100%** | ถามเป็นภาษาไทยได้ทันที ไม่ต้องเรียนรู้คำสั่ง |
| **ข้อมูล Real-time** | ดึงจากฐานข้อมูลจริงของกระทรวง ไม่ใช่ข้อมูลเก่า |
| **AI อัจฉริยะ** | ใช้ Generative AI ระดับเดียวกับ ChatGPT |
| **ฟรี ไม่มีค่าใช้จ่าย** | ประชาชนเข้าถึงได้โดยไม่เสียค่าใช้จ่าย |

## ปัญหาที่แก้ไข

### ❌ ปัญหาเดิม (Before)

| ปัญหา | ผลกระทบ |
|-------|---------|
| **ค้นหาข้อมูลยาก** | ต้องเข้าหลายเว็บไซต์ หลายหน่วยงาน |
| **ข้อมูลกระจัดกระจาย** | ข้อมูล สพฐ, เอกชน, อปท อยู่คนละที่ |
| **ต้องมีความรู้เทคนิค** | ต้องรู้จักระบบฐานข้อมูล, Filter |
| **ไม่รองรับคำถามซับซ้อน** | ถามเปรียบเทียบ หรือ Ranking ไม่ได้ |
| **ไม่มีการแสดงผลเชิงภาพ** | ไม่เห็นแผนที่ ไม่เห็นกราฟ |

### ✅ การแก้ไขโดย DO-MOE AI (After)

| การแก้ไข | ผลลัพธ์ |
|----------|---------|
| **ถามเป็นภาษาไทย** | พิมพ์ "โรงเรียนในปัตตานีมีกี่แห่ง" ได้เลย |
| **รวมทุกสังกัดในที่เดียว** | สพฐ + เอกชน + อปท + อื่นๆ รวม 10+ สังกัด |
| **AI เข้าใจบริบท** | เข้าใจคำถามต่อเนื่อง จดจำ context |
| **รองรับคำถามทุกแบบ** | Count, List, Compare, Ranking, Detail |
| **แผนที่แบบ Interactive** | แสดงตำแหน่งโรงเรียนบนแผนที่ได้ทันที |

## คุณสมบัติหลักของระบบ

### 🔍 1. การค้นหาอัจฉริยะ

```
ตัวอย่างคำถามที่ระบบตอบได้:

📊 นับจำนวน:
   "โรงเรียน สพฐ ในเชียงใหม่มีกี่โรง" → 694 โรง

📋 รายชื่อ:
   "รายชื่อโรงเรียนในอำเภอหาดใหญ่" → 171 โรง + รายชื่อ

🔍 ค้นหา:
   "หาโรงเรียนชื่อเบญจมราชูทิศ" → รายละเอียดครบ

⚖️ เปรียบเทียบ:
   "เปรียบเทียบปัตตานีกับยะลา" → 675 vs 500 โรง

🏆 Ranking:
   "จังหวัดไหนในภาคใต้มีโรงเรียนมากสุด" → นครศรีธรรมราช

📍 ตำแหน่ง:
   "โรงเรียนเตรียมอุดมศึกษาอยู่ที่ไหน" → พิกัด + แผนที่
```

### 🗺️ 2. แผนที่แบบ Interactive
- แสดงตำแหน่งโรงเรียนบน Google Maps
- Zoom เข้า-ออกได้
- คลิกดูรายละเอียดแต่ละโรงได้

### 📊 3. การวิเคราะห์เชิงลึก
- **Breakdown ตามจังหวัด**: เห็นสัดส่วนแต่ละจังหวัด
- **Breakdown ตามสังกัด**: เห็นจำนวนแต่ละสังกัด
- **Trend Analysis**: เปรียบเทียบข้อมูลได้

### 🛡️ 4. ระบบหลังบ้านสำหรับ Admin
- **API Settings**: จัดการ API Keys
- **Prompt Management**: ปรับแต่งบุคลิก AI
- **Session Monitor**: ดู Active Users
- **Analytics**: สถิติการใช้งาน

## เทคโนโลยีที่ใช้

### 🏗️ สถาปัตยกรรมระบบ

```
┌─────────────────────────────────────────────────────────────────┐
│                    🌐 Frontend (Next.js + React)                │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│   │ Chat UI  │  │  Admin   │  │ Analytics│  │   Map    │       │
│   │          │  │  Panel   │  │          │  │  Widget  │       │
│   └──────────┘  └──────────┘  └──────────┘  └──────────┘       │
└─────────────────────────────────────────────────────────────────┘
                               ↓ API
┌─────────────────────────────────────────────────────────────────┐
│                    🐍 Backend (Flask + Python)                  │
│   ┌──────────────┐  ┌──────────────┐  ┌──────────────┐         │
│   │ Query Parser │  │  LLM Engine  │  │   Response   │         │
│   │ (Intent+NLU) │  │ (Groq/Gemini)│  │  Synthesizer │         │
│   └──────────────┘  └──────────────┘  └──────────────┘         │
└─────────────────────────────────────────────────────────────────┘
                               ↓
        ┌──────────────────────┴──────────────────────┐
        ↓                                              ↓
┌──────────────────┐                      ┌──────────────────────┐
│   🗄️ Qdrant      │                      │   🤖 AI Providers    │
│   Vector DB      │                      │                      │
│   56,881 Schools │                      │  Groq (หลัก)         │
│   + Statistics   │                      │  Gemini (สำรอง)       │
└──────────────────┘                      └──────────────────────┘
```

### 🔧 เทคโนโลยีหลัก

| Layer | Technology | เหตุผลที่เลือก |
|-------|------------|---------------|
| **Frontend** | Next.js 14 | SEO-friendly, Fast, Modern |
| **Backend** | Flask (Python) | Flexible, AI Integration |
| **Database** | Qdrant (Vector DB) | Semantic Search, Fast |
| **AI Model** | Groq + Gemini | Speed + Reliability |
| **Caching** | Redis | ลด Latency, ประหยัด API |
| **Auth** | Firebase Auth | Secure, Scalable |
